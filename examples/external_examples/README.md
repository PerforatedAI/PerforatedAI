# External Examples

This folder contains two types of projects:

 - Projects that are links to other repositories we have optimized that are single examples rather than full libraries.  Each folder contains a link to our fork of the project.  The folder here will contain details on the PAI outcomes, while the fork will contain details on running the training.
 - Projects that require the checking out of an external repository as one of the components of the included example.  This generally is intended to be custom models or modules that are not built into pytorch.
